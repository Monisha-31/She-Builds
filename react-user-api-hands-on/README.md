# React User API Hands-On Project

This project demonstrates:

- useState()
- useEffect()
- fetch()
- Loading state
- Error handling
- Displaying API data in a table

API:
https://jsonplaceholder.typicode.com/users

## Run

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   npm install
4. Then run:
   npm run dev
5. Open the URL shown by Vite, usually:
   http://localhost:5173/
