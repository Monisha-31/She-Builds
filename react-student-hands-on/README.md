# React Student Hands-On Programs

This project contains three React hands-on programs.

## Hands-On 1
Student Profile Using Props

Receives:
- name
- rollNo
- course
- college

## Hands-On 2
Student Marks Using Props + State

Receives:
- name
- subject

Uses state for marks and provides Increase Marks / Decrease Marks buttons.

## Hands-On 3
Login Form Using State

Uses useState() for username and password.
Displays:
- Login Successful
- Please enter username and password

## Run in VS Code

Open this folder in VS Code.

Terminal:
npm install

Then:
npm run dev

Open the localhost URL shown by Vite, usually:
http://localhost:5173/
