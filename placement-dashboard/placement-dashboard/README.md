# Student Placement Dashboard (React + Vite)

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in dist/

Demo login: demo@college.edu / demo123 (or register a new student).

## Routes
/login, /register (public) | / (Dashboard), /jobs, /applications, /interviews, /notifications, /profile (protected)

## Deploy
Vercel/Netlify: build command `npm run build`, output directory `dist`.
